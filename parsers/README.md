# Парсеры для сбора данных с маркетплейсов

**Стек:** Python (pandas, glob, re), Excel

**Задача:** автоматизация  обработки и консолидации Excel-выгрузок из личных кабинетов селлера на Ozon и Яндекс Маркете для проекта по оптимизации ассортимента DonorSearch.

| Файл | Что собирает |
|------|--------------|
| `parse_yandex_margin.py` | Транзакции и маржа Яндекс Маркета |
| `parse_market_funnel.py` | Воронка продаж (показы → корзины → заказы) |
| `parse_market_stats.py` | Доставленные, возвращённые, невыкупленные товары |
| `parse_ozon_economics.py` | Юнит-экономика Ozon |
| `parse_ozon_reports.py` | Отчёты по товарам Ozon |
| `parse_ozon_stock.py` | Остатки и ликвидность Ozon |

**Результат:** единые CSV-файлы в папке `Output` для дальнейшего анализа.
